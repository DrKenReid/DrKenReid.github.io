Algorithms, Live

Watching an algorithm work beats reading about one, every time. Each part of this series puts one running live in your browser (ant colonies foraging, populations evolving) with the important parameters as sliders, so you can cause the famous failure modes yourself. Vanilla JavaScript, no libraries, and all the code sits in each page's source, free to steal.
